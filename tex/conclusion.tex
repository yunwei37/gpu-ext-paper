\section{Conclusion}
\label{sec:conclusion}
We presented \sys, a policy runtime that models each GPU resource as an asynchronous state machine whose state transitions are directed by verified eBPF programs across the host-device boundary. Across four workloads, \sys improves throughput by up to $1.76\times$ over application-tuned baselines and reduces tail latency by up to $2\times$, demonstrating that OS kernel extensibility extends effectively to GPU management.
